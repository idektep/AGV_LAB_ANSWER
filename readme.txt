โครงสร้าง Branch (Branch Structure)
----------------------------------------------------

Repository นี้แบ่ง Code Script ตาม "Branch" ดังนี้

- main
  -> ไฟล์ readme.txt เป็นหน้าอธิบายภาพรวมของ Repository

- AGV_WebServer_Answer
  -> เฉลย (Answer) ของ Lab "AGV_WebServer"

- Smart_AGV_Control_Center_Answer
  -> เฉลย (Answer) ของ Lab "Smart_AGV_Control_Center"

- AGV_Status_Monitor_Answer
  -> เฉลย (Answer) ของ Lab "AGV_Status_Monitor"

- Smart_AGV_Answer
  -> เฉลย (Answer) ของ Lab "Smart_AGV"

- AGV_Remote_Hold_Control_Answer
  -> เฉลย (Answer) ของ Lab "AGV_Remote_Hold_Control"

- AGV_Remote_Controller_Answer
  -> เฉลย (Answer) ของ Lab "AGV_Remote_Controller"

หมายเหตุ: ชื่อ Branch แต่ละอันคือชื่อ Lab เดิม + คำว่า "_Answer" ต่อท้าย
เช่น branch "AGV_WebServer_Answer" คือเฉลยของ Lab ชื่อ "AGV_WebServer"
ผู้ใช้งานสามารถ checkout ไปยัง branch ที่ต้องการ เพื่อดูโค้ดเฉลยของ Lab นั้นๆ ได้โดยตรง
